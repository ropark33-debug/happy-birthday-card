# Happy Birthday Card 🎁

인터랙티브 생일 축하 카드 웹페이지입니다.  
HTML5 Canvas와 JavaScript를 사용하여 화면에 나무 가지와 하트가 피어나는 애니메이션 효과를 구현했습니다.

## 🌸 기능 소개
- **하트 트리 애니메이션**: 나무 가지가 자라나며 풍성한 하트 모양의 잎들이 피어납니다.
- **축하 메시지 연출**: 애니메이션 진행 후 부드럽게 생일 축하 문구가 페이드인됩니다.
- **다시 보기 지원**: 버튼을 눌러 언제든지 애니메이션을 다시 감상할 수 있습니다.
- **반응형 디자인**: 다양한 화면 크기에 맞춰 캔버스와 폰트 크기가 자동으로 조절됩니다.
